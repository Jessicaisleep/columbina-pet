# 桌宠手机端 APK（安卓）

这是「手机接着聊」的安卓客户端，和电脑端桌宠配套使用。自签调试包，直接侧载安装，不上架。

- 文件：`dsh-pet-mobile-debug.apk`
- 大小：16.26 MB
- SHA256：`FCF854C2B5D50593DA45DCC179E9575C9E7FC4CD58750B21FE48637E1BB0ED39`

## 怎么用

1. 电脑上打开桌宠 → 右键桌宠（或托盘）打开设置 → 「手机连接」→ 打开开关 → 拿到 6 位配对码。
2. 手机装这个 APK，填电脑的局域网地址（形如 `192.168.0.105:7340`）和那 6 位码。
3. 第一次打开会提示证书不受信任 —— 点「高级」→「继续前往」就行，不需要安装根证书。

## 它和电脑是什么关系

记忆只有电脑那一份，手机是遥控器 + 本地副本。手机设了自己的 API 密钥才会在离开电脑网络时接管记对话，回到同一网络会自动把这段追加回电脑，不丢句、不需要手动合并。

## 能做什么

聊天（含语音输入）、宠物可拖动、主动聊天气泡可点开回话、悬浮宠物、语音唤醒、读屏（把手机屏幕上看到的文字当作上下文）、离线记话回家补。

## 不能做什么

iPhone 没有系统级悬浮；出不了外网（只能同一局域网）；不联网不能自己聊（除非设了手机端密钥）；群聊里的主动发言推不回 QQ 群；悬浮窗与语音唤醒需要系统授权，国产 ROM 可能还要额外放行。
