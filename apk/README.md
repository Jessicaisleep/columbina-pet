# 桌宠手机端 APK（安卓）

这是手机端客户端，和电脑端桌宠配套使用。自签调试包，直接侧载安装，不上架。

- 文件：`dsh-pet-mobile-debug.apk`
- 大小：**100.1 MB**（`104,991,021` 字节）—— 比上一版大很多，因为**电脑端那 150 段动画（含待机循环）已经打进包里**，不连电脑也能看宠物动。
- SHA256：`7E2DF27BCF18CC70BA23F2FE3B436245A4681F597CF65D0FEE0E2D44FBC1FDE0`
- 下载：**不放仓库里**（单文件超过 GitHub 的 100 MiB 限制），改挂在 Release 附件上：
  <https://github.com/Jessicaisleep/columbina-pet/releases/latest>

## 怎么用

1. 电脑上打开桌宠 → 右键桌宠（或托盘）打开设置 → 「手机连接」→ 打开开关 → 拿到 6 位配对码。
2. 手机装这个 APK，填电脑的局域网地址（形如 `192.168.0.105:7340`）和那 6 位码。
3. 第一次打开会提示证书不受信任 —— 点「高级」→「继续前往」就行，不需要安装根证书。

## 它和电脑是什么关系

记忆只有电脑那一份，手机是遥控器 + 本地副本。一台手机可以同时配对**插件端（2 只）**与**独立端（3 只）**，但一次只用其中一份数据，你自己在「切换」面板里选：
换电脑时宠物、历史、离线队列一起换；换宠物时聊天按宠物分域。手机设了自己的 API 密钥才会在离开电脑网络时接管记对话，回到同一网络会自动把这段追加回电脑，不丢句、不需要手动合并。

## 能做什么

聊天（含语音输入）、宠物可拖动、**宠物可切换**、**可在手机上改人设 / 记忆 / 回话节奏 / 主动聊天 / 读屏 / 助手**（配对设备管理只留在电脑端）、主动聊天气泡可点开回话、悬浮宠物、语音唤醒、读屏（把手机屏幕上看到的文字当作上下文）、离线记话回家补。

## 不能做什么

iPhone 没有系统级悬浮；出不了外网（只能同一局域网）；不联网不能自己聊（除非设了手机端密钥）；群聊里的主动发言推不回 QQ 群；悬浮窗与语音唤醒需要系统授权，国产 ROM 可能还要额外放行；配对设备管理（生成配对码、删设备）只在电脑端，手机上不做。
